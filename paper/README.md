# Research-paper materials

`main.tex` and `main.pdf` are retained research materials from the earlier project stage. They are not a report of ModelBoundary Lab v0.6.0 model-inference results. The v0.6.0 tool release has not completed a real pretrained-model inference run or end-to-end Bubblewrap integration test in its build environment; see the root `BUILD_STATUS.json` and `TEST_RESULTS.txt`. The author's separately supplied Zenodo record is https://doi.org/10.5281/zenodo.23442798; this repository build does not claim to have modified that record.
